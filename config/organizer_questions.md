# Standard organizer questions

The agent asks only for information that is still missing from the event record.

1. Event dates and public operating hours
2. Estimated or previous attendance
3. Food-vendor fee
4. Application deadline and whether food-vendor applications are open
5. Expected number of food vendors
6. Exclusivity or conflicting-product restrictions
7. Whether fresh cinnamon-glazed nuts and gourmet popcorn are permitted
8. Tent/trailer requirements and available booth sizes
9. Electricity availability, amperage, and cost
10. Generator rules
11. Health-department or temporary-food permit requirements
12. Insurance/COI requirements
13. Arrival and setup times
14. Overnight security and whether a booth can remain set up
15. Parking and vendor-vehicle access
16. Rain, cancellation, and refund policy
17. Official application link
